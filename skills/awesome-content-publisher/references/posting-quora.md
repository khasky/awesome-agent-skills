# quora

Check: `quora.com` — the home composer reads `What do you want to ask or share?` with `Ask`, `Answer` and `Post` beneath it, and the header carries the account's avatar; a signed-out session gets the login wall instead. Compose: the `Post` control opens the Create Post dialog, which holds `button.puppeteer_test_audience_picker` (defaults to `Everyone`, meaning the personal profile, with the account's Spaces listed under it), one `[contenteditable="true"]`, and `button.puppeteer_test_modal_submit`. Leave the audience alone for a personal post. `Escape` closes the whole dialog, not just a menu, and takes the typed body with it.

The editor is its own block model, neither markdown nor a paste target. Each paragraph is a `div.section[data-type="plain"]`, and images arrive as `data-type="image"` sections. A `fill` lands the first paragraph; everything after it is a real `Enter` keypress followed by `document.execCommand('insertText', ...)` in the next call, which the editor accepts and which carries non-BMP emoji through unharmed. Strip inline backticks and every other marker before typing — nothing renders here, so markers publish as characters.

A typed URL is swallowed and replaced by the target page's own title. `https://github.com/Tencent/teamai-cli` resolved into a `div.span.link` reading `GitHub - Tencent/teamai-cli: Make Every Team AI Native`, with the address gone from the visible text. The published anchor is correct, so this is not a defect to fix, but the sentence introducing the link has to survive it: `Repo, if you want to check your own row:` still reads, while a sentence built around the bare address does not.

The image lands at the caret, so put the caret where it belongs first. The `input[type=file][accept="image/*"]` sits inside the editor wrapper and is never visible, so clicking it through the page times out; `input.click()` from `page.evaluate` opens the chooser that `browser_file_upload` then answers, and the file has to be under an allowed root — copy it there before opening the chooser. A body typed end to end leaves the caret in the last paragraph, which is how one run published the picture between its closing link and its closing question. Quora re-hosts on `qph.cf2.quoracdn.net` within the dialog, and there is no alt-text field anywhere in it.

Read-back: submitting opens the permalink in a new tab, `quora.com/profile/<handle>/<slug built from the opening words of the body>` — there is no title field, so the first sentence becomes the URL. Confirm on that page: the sections in their intended order, the link's `href`, the `qimg` image present, and zero literal backticks or `](http`.

The image goes at the very top and the caret is what puts it there. `Add image` at the bottom of the dialog is the visible control for the same hidden input described above. Because the picture lands at the caret, insert it **first**, before the body: open the dialog, put the caret in the empty first section, add the image, press `Enter` to leave one empty section under it, and only then type the body. Published shape is image, blank line, first paragraph. One run typed the body first and shipped the picture at the bottom; another shipped no picture at all.

The dialog has a formatting menu, and code lines need it. `Aa` (`Text formatting`) at the bottom of the composer opens the menu — Bold, Italic, Quote, **Format code**, Bullets, Numbers, Link. Select the lines that came from a fenced block, then `Format code`: they become a monospace block instead of prose, which is the only way a command reads correctly here. Do this per source block, after the body is in, and assert the block count on the published page against the source's fenced-block count.

Links come from the same menu. A URL typed as text stays text unless Quora swallows it into a title card (above) — neither outcome is a reliable anchor. Select the words that should link, use `Link` from the `Aa` menu, paste the address, and confirm an `a[href]` on the published page for every URL the source carries.
